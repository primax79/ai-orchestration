# 19.5 verification (Codex, 2026-10-30): BOUNCE

Verified on `integration/19` (executor commit 6f0cdfb). `reconcile()` is correct: it is host-aware, legacy records count as local, the last heartbeat is exposed, show/list work, and the scope is respected.

- **B1 (high)**: `scripts/orchestration_runs.py:5782,5800-5833`. `cmd_cancel()` reads `run.json` without checking `host`, then marks a remote run cancelled and signals its recorded PGID/PID. With PID reuse this can kill an unrelated local process, and trigger-confirmed commands inherit the flaw. Fix: apply one shared predicate (local host, normalized as in 19.4, or a legacy record without a host) before any mutation or signal. Reject remote runs. Add direct tests and trigger-path tests.
- **B2 (high)**: `scripts/orchestration_runs.py:6891,6963-6988`. `cmd_cleanup()` has no host guard and can remove a remote run's worktree and force-delete its branch. Fix: refuse cleanup unless the run is local (legacy records without a host count as local), and add regression tests.
