- **B1 (high)**: `scripts/orchestration_runs.py:6513`. If the agent dies from SIGHUP, SIGTERM or SIGKILL/OOM, the supervisor calls `os._exit()` before `_finalize_run_completion()`. No `status.json` is written, so an agent crash shows up as `lost` instead of `failed`. Fix: tell screen-session teardown apart from child failure. For a signalled child, write a failed status atomically with the exit code derived from the signal. Add a real-screen test that kills only the agent PID and asserts `failed`, the exit code and `status.json`.
- **B2 (medium)**: `scripts/orchestration_runs.py:5128`. The log path, derived from the workspace, is interpolated into `screenrc` without escaping; a newline in the path allows directive injection. Fix: drop the `logfile <path>` directive, rely on `-Logfile` (already argv), and keep only constant directives. Add a test with an adversarial workspace path.
